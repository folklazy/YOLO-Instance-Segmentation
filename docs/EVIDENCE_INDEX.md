## Private artifacts

Private audit ของงานจัดส่งมอบใช้ logical root `YOLO-Instance-Segmentation.local/curation-20261119` มี full file inventory, before-hashes และ test logs ผลรวมที่เผยแพร่ได้อยู่ใน [VALIDATION.json](../provenance/VALIDATION.json)
